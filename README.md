# Cyber Security Infographic

## Project Title
Cyber Security: 5 Simple Ways to Stay Safe Online

## Task
Task 4 – Infographic

## Tool Used
Canva

## Description
A clean and informative infographic presenting five simple ways to stay safe online. The design focuses on readability, visual hierarchy, icons, numbering, and a consistent color palette.

## Key Topics
1. Use Strong Passwords
2. Enable Two-Factor Authentication
3. Be Careful With Phishing
4. Keep Your Software Updated
5. Protect Your Personal Information

## Output
High-resolution PNG infographic designed at 800 × 2000 px.

## Color Palette
- Deep Navy Blue: #0B1F3A
- Purple: #6C63FF
- Dark Gray: #333333
- Light Background: #F7F8FC
